# Summary

Kubeadm initialization establishes the configured first control plane, while joining connects additional nodes through discovery and credential bootstrap. Worker and control-plane roles require different local responsibilities.

Static manifests, runtime preparation and Pod networking are separate stages. A successful bootstrap statement does not prove every participant is ready, and reset is not a universal reversal of external or network changes.
