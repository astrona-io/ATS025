# Create and manage Kubernetes clusters using kubeadm

This section covers create and manage Kubernetes clusters using kubeadm. You will study Initial Control Plane And Joining Nodes. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Distinguish initialization from worker or control-plane joining.
- Explain static manifests and runtime bootstrap.
- Evaluate discovery trust and temporary credentials.
- Identify the stage that blocks node readiness.
