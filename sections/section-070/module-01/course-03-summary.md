# Summary

Networking, storage and runtime interfaces connect different implementations to core orchestration. Installed tools and plugins have distinct responsibilities and cannot be treated as interchangeable integration providers.

Supported endpoints, permissions and capabilities determine usable behavior. Identify whether execution, network preparation or storage operations failed before selecting an extension correction.

Runtime connectivity, artifact availability and application startup need separate evidence.
