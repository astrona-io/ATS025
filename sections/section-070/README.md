# Understand extension interfaces (CNI, CSI, CRI, etc.)

This section covers understand extension interfaces (CNI, CSI, CRI, etc.). You will study Networking, Storage And Runtime Interfaces. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Distinguish CNI, CSI and CRI responsibilities.
- Identify core-to-extension integration points.
- Evaluate optional driver and policy capabilities.
- Diagnose the responsible extension stage.
