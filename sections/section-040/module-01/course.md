# Supported Upgrade And Node Maintenance

This module develops supported Upgrade And Node Maintenance. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Explain supported component-version and upgrade order.
- Distinguish cordon, drain and disruption policy.
- Evaluate datastore snapshot scope and restore prerequisites.
- Verify component and application recovery after lifecycle changes.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
