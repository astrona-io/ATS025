# Custom APIs And Operator Installation

This module develops custom APIs And Operator Installation. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Explain custom schema registration and discovery.
- Distinguish controller installation from desired-instance acceptance.
- Evaluate controller permissions and dependencies.
- Interpret status, versions and cleanup contracts.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
