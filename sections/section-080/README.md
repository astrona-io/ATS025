# Understand CRDs, install and configure operators

This section covers understand CRDs, install and configure operators. You will study Custom APIs And Operator Installation. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Explain custom schema registration and discovery.
- Distinguish controller installation from desired-instance acceptance.
- Evaluate controller permissions and dependencies.
- Interpret status, versions and cleanup contracts.
