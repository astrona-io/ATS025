# Prerequisites

- The `astrona` command-line tool, installed and working (`astrona check` passes).
- A container engine that kind can use (Podman or Docker) with about 2 GiB of free memory.
- `kubectl`.
- You can write a CRD with a schema, defaults, validation rules and subresources, and you can wire an operator with least privilege.

The lab starts a kind cluster (Kubernetes 1.35). The commands for the lab are in the README of this folder.
