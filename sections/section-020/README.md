# Prepare underlying infrastructure for installing a Kubernetes cluster

This section covers prepare underlying infrastructure for installing a Kubernetes cluster. You will study Host Prerequisites And Installation Topology. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Identify host identity and capacity prerequisites.
- Explain kubelet runtime compatibility.
- Plan non-overlapping network address ranges.
- Evaluate version, trust and required connectivity.
