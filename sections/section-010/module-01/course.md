# Role Rules, Bindings And Administrative Authority

This module develops role Rules, Bindings And Administrative Authority. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Explain roles, bindings and scope.
- Evaluate additive effective grants.
- Identify indirect privilege through workload creation.
- Choose least privilege for an administrative responsibility.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
