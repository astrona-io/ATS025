# Manage role based access control (RBAC)

This section covers manage role based access control (RBAC). You will study Role Rules, Bindings And Administrative Authority. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Explain roles, bindings and scope.
- Evaluate additive effective grants.
- Identify indirect privilege through workload creation.
- Choose least privilege for an administrative responsibility.
